# cassnoccurrences 1.0.0

First tagged release.

* Stages CASSN ingest metadata and Motus receiver databases for an occurrence build.
* Builds one standardized occurrence CSV from Wildlife Insights, NABat/SonoBat, and Motus inputs.
* Writes a build receipt recording package and Git state, R session details, parameters, output dimensions, and output SHA-256.
* Ships the occurrence data dictionary and source-field mapping (`inst/documentation/CASSN_Metadata_Mapping.xlsx`).
